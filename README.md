# Create Ribbon

### This script automatically creates ribbons! How neat (⁠╹⁠▽⁠╹⁠)


This is a Maya script written mostly for personal use, so the naming conventions are specific to what I like to use in my rigs.

The naming convention for controls are as follows: control group = **L_shoulder_IK/FK_CTRL_GRP**, offset group = **L_shoulder_IK/FK_OFFSET_GRP**, control = **L_shoulder_IK/FK_CTRL**.

The script includes options to create custom ribbons with various settings and to create a ribbon from a joint chain.
